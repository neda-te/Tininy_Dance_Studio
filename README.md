# Балет Тинити — учебен проект

Сайт на български с HTML, CSS и JavaScript, без зависимости.

- `dist/index.html` — съдържание и структура.
- `dist/styles.css` — цветове, шрифтове и подредба за различни екрани.
- `dist/script.js` — мобилно меню.

Отвори `dist/index.html` в браузър или изпълни:

```powershell
python -m http.server 5173 --directory dist
```

Отвори http://localhost:5173. Спиране: Ctrl+C.

Първо упражнение: промени `--purple` в началото на CSS файла, запази и презареди страницата. Промени ширината на браузъра, за да видиш действието на правилата `@media`.

За допълване: лого, истински снимки с разрешение за използване, преподаватели, възрастови групи, график, такси, телефон, точен адрес и социални профили. Абстрактната композиция е направена с CSS и не представлява снимка на школата. Няма форма за събиране на лични данни.
